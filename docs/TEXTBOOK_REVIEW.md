### 1. 트리 거리 활동을 첫 번째로 권하는 이유

교과서는 생물 계통도의 두 개체 사이 이동 거리를 구하고, 반복 구현을 재귀로 바꾸는 활동까지 연결합니다. 현재 부모·자식·깊이를 읽는 기능에 실제 해결할 문제를 더할 수 있습니다. 이 활동의 ‘유전 거리’는 교과서에서 정의한 트리 이동 간선 수이며 실제 생물학적 거리 추정 기능으로 소개하지 않습니다.

- 교과서 7개 노드 예제는 현재 정점 8개 한도 안에 들어갑니다.
- A–G는 거리 3, D–E는 공통 조상 B·거리 2, F–G는 공통 조상 E·거리 2입니다.
- 예상 질문: ‘깊이가 같은 두 노드에서 탐색을 끝내도 될까?’ 관찰 후 두 노드가 실제로 같아지는 시점과 비교합니다.
- 현재 트리 탐색은 부모→자식 방향입니다. D에서 E로 이동하는 거리 활동에서는 부모를 따라 올라가야 하므로, 기존 BFS 결과를 거리 답으로 재사용하거나 간선 방향을 몰래 바꾸지 않습니다. 별도의 트리 거리 실행기가 필요합니다.
- 이진 배열 버전에서는 인덱스 i의 부모가 ⌊i/2⌋임을 관찰하고, 일반 트리 버전에서는 실제 부모·깊이를 사용하도록 구분합니다.

### 2. 스택 활동의 권장 범위

먼저 교과서처럼 사칙 연산과 괄호 없는 제한된 입력으로 시작합니다. 이후 괄호·여러 자리 숫자 지원 여부를 명시적으로 확장할 수 있습니다. 자유 Python 실행으로 소개하지 않습니다.

- 변환: 입력 토큰 → 연산자 우선순위 비교 → 스택 변화 → 출력 누적을 같은 Step으로 표시합니다.
- 계산: `5 3 2 * +`의 결과 11까지, 두 번의 pop과 계산 결과 push를 구분합니다.
- 뺄셈·나눗셈은 먼저 꺼낸 값이 오른쪽 피연산자임을 표시합니다. 덧셈만으로 검증하면 이 오류를 놓칠 수 있습니다.
- 잘못된 토큰, 피연산자 부족·과잉, 0으로 나누기를 설명하고 이전 단계로 복원할 수 있어야 합니다.

### 3. 추가 재귀의 완료 조건

유클리드는 교과서의 `f(a,b) → f(b%a,a)`, `a=0` 종료 규칙을 표시 코드와 일치시킵니다. 252와 105의 결과 21을 확인하며 입력 교환을 독립된 사건으로 임의 추가하지 않습니다.

진법 변환은 호출 순서와 출력 순서를 나누어 보여 줍니다. 123의 이진 표현 1111011을 확인하고, 0 입력의 출력 및 지원 기수를 명시합니다. k진법 확장 시 10 이상인 자리의 문자 표기 정책은 별도 선택입니다.

조합은 두 매개 변수와 기저 조건을 보여 주고, 하노이는 함수 호출 수와 실제 원판 이동 횟수를 분리합니다. 작은 n에서 시작하고 실행·그림 한도를 미리 정합니다.

### 4. 연산량 비교의 집계 기준

PDF 149 / 인쇄 158쪽의 연산 횟수는 코드 줄을 기준으로 세며, 현재 앱의 비교·대입·산술·호출별 집계와 정의가 다릅니다. 교과서의 수치를 앱의 측정값으로 그대로 사용하지 않고 각 그래프에 입력 크기 n의 의미, 집계 대상과 단위를 명시해야 합니다. 실제 실행에서 센 횟수, 경과 시간, 이론적 복잡도를 구분하고 몇 개 입력의 측정만으로 Big-O를 확정하지 않습니다.
