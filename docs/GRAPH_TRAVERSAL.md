# 그래프·트리와 BFS/DFS 계약

사용자의 ‘그래프, 트리 + BFS/DFS’ 요청에 따라 1차 MVP의 그래프 탐색 범위를 구현했습니다. 교과 개념을 바탕으로 만든 예제이며 박물관의 모든 경로 열거 문제나 8퍼즐을 재현한 것은 아닙니다.

## 실습 순서

1. **그래프와 탐색** 또는 **트리와 탐색** 메뉴에서 예제를 고릅니다.
2. 시작·목표·이웃 순서·BFS/DFS를 선택합니다. 연결 편집을 펼쳐 정점·간선, 행렬 또는 리스트를 바꿀 수 있습니다.
3. 문자 입력을 바꿨다면 **표현 적용**으로 검증합니다. 이후 **탐색 준비**를 누르면 초기 상태부터 시작합니다. 트리는 이때 루트와 전체 연결도 검증합니다.
4. 다음 상태를 예상하고 **다음**을 누릅니다. 코드, 현재 정점, 큐·프레임, 방문·처리 기록, 집계가 같은 Step으로 바뀝니다.
5. **BFS·DFS 결과 비교**는 동일 입력으로 만든 두 실행의 독립된 최종 기록을 보여 줍니다. 비교를 열면 자동 재생은 멈추고, 현재 단계는 유지됩니다. **BFS/DFS 단계 보기**와 상단 **BFS/DFS 과정**은 각 실행의 위치를 따로 기억하며 여섯 영역을 전환합니다. 코드로 포커스를 이동하며 전환할 때 자동 실행을 멈춥니다. 입력 변경 시 두 실행과 관찰 위치를 초기화합니다.

입력·설정 변경은 기존 실행과 비교 기록을 지웁니다. 문자 편집 중에는 다른 표현과 구조 편집, 탐색 준비를 잠그고 적용·취소를 안내합니다. 예제를 다시 고르면 그 예제의 연결로 문자 초안도 초기화합니다. 정점 선택·확대·패널 펼침은 표시만 바꾸므로 재생 상태를 지우지 않습니다.

연결 편집 안의 **편집 중인 그래프**는 현재 그래프 모델만 보여 주는 실행 전 미리보기입니다. 정점·간선 변경은 바로 반영하고, 미적용 문자 입력은 마지막으로 적용한 연결임을 표시합니다. 잘못된 트리도 연결 그림을 보며 수정할 수 있지만 탐색 준비의 검증을 통과해야 실행합니다. 미리보기에는 발견·방문·경로 등 실행 상태를 넣지 않습니다.

## 하나의 그래프 모델

### 그림에서 직접 편집

사용자의 GUI 편집 요청에 따라 미리보기에 다음 도구를 추가했습니다. **선택·이동**은 정점을 끌어 배치하고 **자동 배치**로 되돌립니다. **정점 넣기**는 빈 곳에 다음 미사용 알파벳을 추가합니다. **연결하기 / 연결 지우기**는 두 정점을 순서대로 선택하며, 연결 지우기에서는 간선 자체를 눌러도 됩니다. **정점 지우기**는 해당 정점과 연결 간선을 제거합니다. 마지막 정점 삭제·자기 루프·용량 초과는 오류로 안내합니다.

정점과 간선은 Tab→Enter/Space로도 조작할 수 있으며 기존 입력·선택 방식의 추가·삭제 버튼을 유지합니다. 문자 초안이 있으면 그림 수정 도구를 잠가 덮어쓰기를 막습니다. 연결 변경은 동일한 그래프 모델을 갱신하고 행렬·리스트에 바로 반영합니다. 위치 이동은 편집기 안의 표시 좌표만 변경하며 실행 기록을 초기화하지 않습니다. 실행 그림은 자동 배치를 사용합니다.

유효한 트리는 선택한 루트 기준의 계층 배치로 미리 보여 줍니다. 일시적으로 다중 부모·사이클 등이 생기면 실제 연결 그림을 유지하며 탐색 준비에서 오류를 안내합니다. 그림을 움직이는 것으로 부모·자식이나 이진 배열의 좌우 슬롯을 바꾸지는 않습니다.

### 연결 표현

`structures/graph.ts`가 정점 순서, 방향 여부, 간선의 유일한 기준입니다.

- 정점: 중복 없는 A–Z 한 글자, 1–8개. 자기 루프·중복 간선은 거절합니다. 최대 간선은 방향 56개, 무방향 28개입니다.
- 무방향 간선은 정점 순서에 맞춰 한 쌍만 저장합니다. 행렬에는 두 대칭 위치로 나타냅니다.
- 행렬 입력: 현재 정점 순서의 정사각 행렬, 공백으로 구분한 0/1, 대각선 0. 비대칭 무방향 행렬을 자동 보정하지 않습니다.
- 리스트 입력: 각 정점에 한 행씩 `A: B C`. 행 순서가 정점 순서가 됩니다. 고립 정점은 `A:`로 남깁니다. 이웃 표기는 정점 순서로 정규화합니다. 무방향은 양쪽 행에 연결을 적어야 합니다.
- 문자 표현은 1,024자까지 허용합니다. 연결 표현 사이를 왕복해도 그래프가 같습니다.
- 무방향→방향 전환은 양방향 간선을 생성합니다. 방향→무방향 전환은 서로 반대인 간선을 병합합니다. 화면에 전환 정책을 안내합니다.
- 정점 삭제는 해당 정점의 간선도 제거합니다. 시작·루트가 삭제되면 남은 첫 정점으로, 목표가 삭제되면 미지정으로 바뀌며 새 입력을 적용해야 합니다.

그림은 방향 화살표, 현재 정점, 발견, 대기·호출 중, 처리 완료를 글자·기호와 색으로 표현합니다. 확인 중 간선은 주황 점선, 발견한 목표 경로는 파란 선입니다. 선택 테두리는 현재 실행 위치와 별개입니다. 정점을 클릭하거나 Tab→Enter/Space로 선택하고 관계를 확인합니다. 75–200% 확대와 그림 내부 스크롤을 제공합니다.

## 트리

이 실습의 트리는 **부모→자식 방향**으로 입력합니다. 루트의 부모는 0개, 나머지 정점의 부모는 각각 1개이고 루트에서 모두 도달해야 합니다. 다중 부모, 잘못된 루트, 단절과 사이클을 거절합니다. 편집 중 일시적으로 잘못된 트리는 만들 수 있으나 탐색에 적용할 수 없습니다.

`treeInfo`가 루트, 부모·자식·형제, 단말 여부, 깊이(루트 0), 높이와 배열 위치를 계산하고 Step의 `tree` 구조에 저장합니다. 원래 트리의 부모와 탐색 중 발견한 부모는 화면에서 구분합니다. 루트와 다른 정점에서 시작하면 그 정점 아래의 도달 가능한 부분만 탐색합니다.

자식이 최대 둘이면 이진 트리 배열을 제공합니다. 루트 1, 왼쪽 2i, 오른쪽 2i+1, 부모 ⌊i/2⌋이며 0번은 사용하지 않습니다. **정점 순서의 첫 자식을 왼쪽으로, 하나뿐인 자식도 왼쪽으로 두는 규칙**입니다. 독립적인 왼쪽/오른쪽 슬롯 편집은 제공하지 않습니다. 비어 있는 인덱스는 ‘빈칸’으로 남깁니다. 정점이 셋 이상의 자식을 가지면 일반 트리로 표시하고 이진 배열 규칙을 적용하지 않습니다.

## 탐색 의미와 코드

`examples/graph-search.ts`가 Python 표시 코드, 줄 매핑, 실행과 파생 상태를 함께 생성합니다. adj와 빈 visited/order/processed/parent, BFS의 deque, DFS 함수 정의는 초기 상태에서 준비합니다. 준비 비용과 내장 메서드 내부 구현은 추적하지 않습니다. 이후 코드 행의 실행 **후** 상태를 기록합니다. Python 집합 visited는 직렬화와 발견 순서 관찰을 위해 스냅샷에서 목록으로 표현합니다.

| 사건      | BFS                               | 재귀 DFS                                |
| --------- | --------------------------------- | --------------------------------------- |
| 발견      | visited.add 후, 큐 삽입 전        | 호출 진입 후 visited.add                |
| 방문      | 큐에서 꺼낸 후 order.append       | 발견 직후 order.append                  |
| 다음 후보 | Front부터 꺼낸 정점의 이웃        | 현재 프레임의 이웃을 순서대로           |
| 중복      | 이미 발견한 이웃은 삽입하지 않음  | 이미 발견한 이웃은 호출하지 않음        |
| 처리 완료 | 해당 정점의 이웃을 모두 확인한 뒤 | 자식 호출까지 복귀한 뒤                 |
| 저장 구조 | 처리 중 정점을 제외한 대기 큐     | 현재 호출과 복귀를 기다리는 조상 프레임 |

BFS 큐는 기존 `applyLinearCommand`의 FIFO 모델을 재사용합니다. 내부에서는 정점 인덱스를 저장하고 Step의 items/removedValues는 정점 이름으로 변환합니다. remove 사건의 반환값과 전역 u는 꺼낸 정점입니다. 프런티어 스냅샷은 전이 그림 없이 현재 순서·포인터와 changes로 변화를 표현합니다.

DFS는 호출마다 고유 ID와 부모 호출, 매개 변수 u, 지역 변수 v, 복귀 줄을 보관합니다. return은 실제 None 반환과 프레임 제거 후 상태이며 returnInfo에 제거 ID·부모·복귀 줄이 남습니다. 방문 집합은 복귀할 때 지우지 않습니다. 원래 그래프 그림과 탐색 부모 기록이 전체 발견 관계를 보존하고, 콜 스택은 살아 있는 프레임만 담습니다.

이웃 방문 순서는 전체 정점 순서 또는 그 역순을 각 인접리스트에 적용합니다. 표시 코드의 adj와 메타데이터 neighborOrder도 같은 순서입니다. 시작 정점에서 닿는 영역만 탐색하며, 다른 연결 요소에서 자동으로 재시작하지 않습니다. 목표를 찾아도 그 영역 전체를 끝까지 처리합니다.

탐색 부모를 처음 정한 경로를 저장합니다. BFS 경로는 모든 간선 비용이 1이라는 현재 전제에서 최단입니다. DFS는 최단을 보장하지 않습니다. `distances`는 발견 경로의 간선 수이며 DFS에서는 최단 거리라는 뜻이 아닙니다. 목표=시작이면 경로에 정점 하나와 간선 수 0이 표시됩니다.

## SearchState와 집계

`algorithm/start/target`, `current/currentEdge`, `discovered/visitOrder/processed`, `frontier`, `parents/distances`, `path/targetPath`, `pruned`, `outcome`을 저장합니다. path는 현재 정점까지, targetPath는 목표까지 이미 발견한 경로입니다. pruned는 최근 중복 후보와 건너뛴 이유이며, 미탐색 하위 상태 수를 추정하지 않습니다.

완료 전 outcome은 pending입니다. 정상 완료할 때 목표 미지정은 traversed, 목표에 닿았으면 found, 닿지 못했으면 unreachable입니다. 한도 도달은 pending과 직전 상태를 유지하므로 도달 불가로 표시하지 않습니다.

- discoveries: visited에 추가한 정점 수.
- visits: order에 기록한 횟수.
- edgeScans: for가 가져온 실제 이웃 수. 무방향 간선은 양 끝에서 각각 셉니다.
- skipped: 이미 발견한 이웃을 만난 횟수.
- finished: processed에 기록한 횟수.
- comparisons: 방문 여부 if와 BFS while의 참·거짓 검사. for의 반복자 종료 검사는 제외합니다.
- assignments: 실행 중 parent 항목, u·v 대입. 준비 코드와 매개 변수 바인딩은 제외합니다.
- calls/maxDepth: DFS 호출 횟수/동시 프레임 최대 수. BFS는 0입니다.
- inserts/removes/maxSize: BFS 큐 삽입·삭제 횟수, 최대 대기 큐 크기. DFS의 maxSize는 최대 프레임 수입니다.

지표는 중복되므로 합산하지 않습니다. 화면의 O(V+E)는 준비된 인접리스트와 상수 시간 집합 연산을 전제로 한 도달 영역 전체 탐색의 이론입니다. 스냅샷 복제, 코드 생성, 그래프 검증, 파생 경로 계산, 렌더링 비용이나 실제 실행 시간을 뜻하지 않습니다.

## 한도와 비교의 제한

일반 그래프·트리는 최대 정점 8개와 중복 방지로 호출 깊이도 최대 8입니다. 최대 500개 Step(초기·종료 포함)을 동기 생성하며, 최대 56개 방향 간선의 전체 탐색도 한도 내에서 끝납니다. 실행 한도 선택은 화면에서 제거하고 기본 안전 한도를 적용합니다. 낮은 한도에서의 미완료 상태는 단위 테스트로 검증합니다. 한도에 도달하면 마지막 안전한 스냅샷을 보존합니다. 자동 실행 정지는 이미 생성한 기록의 **재생 정지**입니다. 별도 [미로 활동](MAZE.md)은 같은 탐색 엔진을 최대 315칸·2,000개 저장 단계로 Worker에서 실행하며 발견 장면만 기록합니다. 이 확장이 일반 그래프의 입력 제한을 바꾸지는 않습니다.

비교는 같은 그래프·시작·목표·이웃 순서·한도로 만든 별도 실행의 결과 카드와 단계별 과정 전환을 제공합니다. 두 알고리즘의 동시 단계 재생이나 방문량 증가 그래프는 제공하지 않습니다. 한쪽이 한도에 도달하면 미완료로 표시하며 완료 결과로 간주하지 않습니다. 가중치, 8퍼즐, 모든 경로 열거, 경로별 visited 해제, 최소 신장 트리는 이번 범위에 포함하지 않았습니다.
