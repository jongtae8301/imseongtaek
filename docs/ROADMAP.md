# 개발 범위와 다음 단계

AGENTS.md와 기획안의 3단계 범위를 유지합니다. 그래프·트리와 BFS/DFS 이후 사용자의 ‘이어서 진행’ 요청에 따라 1차 MVP의 일반 함수·추가 재귀와 반복 비교를 보완했습니다.

## 이번에 구현한 기반

- 공통 Step 계약, JSON 가능 불변 스냅샷, 메타데이터와 한도 구분
- 알고리즘/Step 기록/재생/시각화 분리
- 1~n 합 재귀 예제의 전체 호출·복귀 흐름
- 여섯 공통 화면과 브라우저 내부 재생
- 입력 검증, 프레임·반환 추적, 누적 집계와 복원
- 한국어 학습 안내, 작은 화면 배치와 키보드 조작
- 중간 상태 단위 테스트와 브라우저 통합 검사
- 동일 모델을 사용하는 큐·스택 직접 조작 및 은행/객차 예제
- FIFO/LIFO, 포인터, 용량·입력 한도, 빈 구조 처리와 거절 기록
- 같은 1~4 입력·연산으로 두 자료구조의 삭제 순서를 관찰하는 활동
- 방향·무방향 그래프 편집, 행렬·리스트 왕복과 입력 검증
- 사용자 요청에 따른 그래프·트리 그림 편집: 정점 드래그·추가·삭제, 두 정점 연결과 간선 삭제, 문자 표현과 동기화
- 새 미로 변형 활동: 벽·출발·출구 편집, 같은 미로의 BFS/DFS 출구 발견 시점·경로·탐색량 비교, 최대 49칸 Worker 준비
- 후속 사용자 요청으로 미로를 코드 없는 비교 전용 화면으로 간소화: 항상 보이는 두 그림에서 공유 미로 편집, 새 발견 장면의 동시 재생·이전 복원, 먼저 찾은 쪽의 경로 유지, 발견 칸 수·이동 횟수 비교
- 트리 관계·깊이·1기반 이진 배열과 잘못된 트리 거절
- 같은 Step의 BFS 큐·DFS 프레임, 발견·방문·처리 완료와 탐색 부모·경로
- 고정/역순 이웃 순서, 단절·사이클·한도 처리, 같은 입력의 BFS/DFS 결과 비교
- 일반 함수의 중첩 호출·지역/전역 범위 변경·None 반환
- 팩토리얼·피보나치와 합의 반복 구현, 같은 입력·한도의 재귀/반복 비교와 독립된 관찰 위치
- 실제 부모·자식 관계를 표현하는 다중 호출 트리, 완료 가지 접기·펼치기·글자 확대
- 검토 후 사용자의 개선 진행 요청에 따라 방식별 학습 안내, 호출 인수/현재 매개 변수 구분, 편집 미리보기, 관찰 집중 화면과 모바일 탭, BFS/DFS 과정 전환을 보완

교과서 검토 후 첫 우선순위인 트리 거리·최소 공통 조상을 구현했습니다. 깊이 비교 및 이진 배열 인덱스 방식, 두 포인터·이동 기록·경로와 한도 처리를 제공합니다. 재귀 거리 구현과 방법별 독립 관찰 위치를 유지하는 비교는 후속 범위입니다.

사용자의 화면 간소화 요청으로 taste-design을 적용했습니다. 상시 사이드 메뉴와 중복 제목을 줄이고, 기본 화면을 시각화·정보 탭과 접힌 설정으로 바꿨습니다. 모든 실습 기능과 여섯 Step 영역은 유지하며 전체 펼치기도 제공합니다. 기준은 [DESIGN.md](../DESIGN.md), 동작은 [관찰 화면](OBSERVATION.md)에 기록했습니다.

2026-09-13에는 사용자가 지적한 내부 스크롤의 잘림을 줄이기 위해 패널 높이 제한을 제거하고 페이지 세로 스크롤을 적용했습니다. 긴 실행 기록의 접기·펼치기와 재생 바 높이에 따른 하단 여백을 추가했습니다. 실행 엔진과 Step 계약은 유지합니다.

## 1차 MVP에서 남은 일

1. 유클리드 알고리즘·진법 변환·조합·하노이 탑 등 추가 재귀 활동
2. 큐·스택을 8퍼즐·표현식으로 연결하는 추가 활동
3. 예제 선택과 모듈별 구조 렌더러 등록 체계의 추가 확장

## 이후 확장

| 단계 | 범위                                                                            |
| ---- | ------------------------------------------------------------------------------- |
| 2차  | 순차·이분 탐색, 전체 탐색, 백트래킹, 상태 공간 트리, 분기 한정법, 탐욕법        |
| 3차  | 분할 정복, 합병 정렬, 동적 계획법, 메모이제이션, 동적 테이블, Big-O 분석 고도화 |

8퍼즐은 큐·그래프 탐색 기반을 갖춘 이후 통합 수업 시나리오로 연결합니다.

## 알려진 제한

- 일반 함수·합/팩토리얼/피보나치의 재귀·반복, 큐·스택, 그래프·트리와 BFS/DFS를 제공합니다. 함수와 BFS/DFS 비교는 최종 기록 카드 및 각 방식의 위치를 기억하는 과정 전환을 제공합니다. 두 실행을 동시에 자동 재생하거나 범용 Python을 실행·편집하지 않습니다.
- 호출 트리는 현재 최대 67개이며 완료 가지 접기·글자 확대·스크롤을 제공합니다. 더 큰 다중 재귀와 메모이제이션은 별도 설계가 필요합니다.
- 큐·스택은 논리적 원소 순서를 표현합니다. 실제 메모리 배치·순환 큐의 인덱스·내장 메서드 내부 실행은 다루지 않습니다.
- 오류/취소 상태, 동적 테이블 타입은 확장 계약이며 해당 실행기·화면의 완성을 뜻하지 않습니다.
- 그래프는 정점 8개까지, 가중치·자기 루프·중복 간선 없이 시작점의 도달 영역만 탐색합니다. 트리 배열은 첫 자식을 왼쪽에 두는 규칙이며 왼쪽/오른쪽 슬롯을 따로 편집하지 않습니다.
- 작은 정수 입력의 실행은 제한된 동기 계산입니다. 대규모 탐색에는 Worker/청크 실행을 먼저 도입해야 합니다.
- 연산 횟수만 집계하며 실제 시간 측정·복잡도 비교 그래프는 없습니다.
- 로컬 저장·파일 내보내기·서버 전송을 제공하지 않습니다.
- 실제 교실 적용, 교사 검토, 실제 모바일 기기와 다른 브라우저의 검증, 외부 배포는 별도 작업입니다.

화면과 테스트의 완성은 교육 효과가 확인되었다는 뜻이 아닙니다. 실제 수업에서는 학생의 예상과 설명 활동을 통해 확인합니다.
