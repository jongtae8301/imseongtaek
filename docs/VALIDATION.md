## 트리 거리·LCA 추가 검증

- 깊이/배열 방식 각각 교과서 49개 노드 쌍의 경로·거리를 독립적인 무방향 BFS와 대조, 알려진 깊이로 LCA 확인
- 일반 트리 25개 노드 쌍, 루트 단독·같은 노드·최대 8개 편향 트리·알파벳순과 다른 정점 순서 확인
- D–E의 두 방식에서 첫 이동 대상이 다름(깊이 D→B, 배열 E→B), 최종 거리 2·공통 조상 B·경로 D→B→E 일치
- 부모 이동 직후 distance=0, 다음 대입 후 1로 증가. 두 포인터가 만나도 lca 대입 전에는 최종 경로를 표시하지 않음
- 조건·대입·산술·반복의 사건별 증가, 모든 중간 한도에서 직전 상태 보존, JSON·깊은 동결·왕복·처음으로 검증
- 일반 트리의 배열 방식, 잘못된 루트·방향·여러 부모·분리된 사이클·미등록 노드·한도 입력을 거절
- 새 브라우저 시나리오 4개를 데스크톱·모바일에서 검증(총 8개): 여섯 영역 동기화·키보드 복원, 방법/노드 변경 정지, 한도/편집 오류 수정, 집중 화면/모바일 탭과 활동 전환
- 기존 그래프·트리 브라우저 검사 10개도 통과. 이 확장에서는 기존 전체 42개 브라우저 검사를 다시 실행하지 않았음

첫 데스크톱 검사에서는 새 테스트가 ‘트리와 탐색’이라는 정확한 이름만 찾았지만 실제 접근성 이름에는 메뉴 번호 04가 포함되어 선택에 실패했습니다. 번호 유무를 허용하는 선택자로 수정한 뒤 데스크톱 4개 모두 통과했습니다. 실제 캡처에서 부모 이동 전후 포인터·경로·코드·현재 상태를 확인하고 작은 그림의 노드 이름과 상태 글자를 키웠습니다.
