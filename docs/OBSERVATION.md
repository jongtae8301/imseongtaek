# 관찰 화면과 비교 과정 전환

‘정보가 많아 복잡하다’는 사용자의 디자인 개선 요청에 따라 기본 화면에서 동시에 보여 주는 영역을 줄였습니다. 알고리즘·Step 스키마·예제는 유지하며 정보 위계와 표시 방법을 변경했습니다. 이후 패널 내부 스크롤로 내용이 잘린다는 사용자 요청에 따라 세로 탐색을 페이지 스크롤로 통일했습니다. 시각 기준은 [DESIGN.md](../DESIGN.md)에 기록합니다.

- **상단 메뉴**: 함수와 재귀, 큐와 스택, 그래프와 탐색, 트리와 탐색으로 이동합니다. 작은 화면에서는 같은 메뉴의 이름을 짧게 표시합니다.
- **예제·설정**: 기본은 접힌 상태입니다. 이 버튼으로 예제·입력·방법·그래프 편집을 열고 ‘설정 닫기’로 접습니다. 입력 오류·미적용 안내는 접어도 보입니다. 큐·스택 직접 조작의 삽입·삭제와 트리 활동 전환은 항상 접근할 수 있습니다.
- **넓은 화면**: 900px를 초과하면 큰 시각화와 선택한 정보 패널을 두 열로 보여 줍니다. 오른쪽 탭은 코드·현재 상태·자료구조·실행 기록·분석이며 처음에는 코드를 선택합니다. 코드·구조·상태는 내용 높이만큼 펼쳐 페이지 전체로 세로 스크롤합니다. 가로로 긴 코드·표·구조만 패널 안에서 좌우로 스크롤합니다.
- **좁은 화면**: 900px 이하에서는 시각화를 포함한 여섯 탭 중 한 영역만 표시합니다. 처음에는 시각화를 선택합니다. 화면을 넓힐 때 시각화를 선택한 상태라면 오른쪽에는 코드를 보여 줍니다.
- **모두 펼치기**: 여섯 영역을 두 열(900px 이하 한 열)로 표시합니다. ‘간단히 보기’로 돌아오면 이전에 선택한 탭을 복원합니다.
- **실행 기록**: 현재 단계까지의 최근 8개를 먼저 표시합니다. ‘이전 기록 N개 펼치기’로 현재 단계까지 모든 기록을 열고 ‘최근 8개만 보기’로 접습니다. 접힌 수를 명시하며 기록·집계를 삭제하지 않습니다. 펼친 상태에서도 기록을 눌러 이전 단계로 이동할 수 있고, 아직 실행하지 않은 미래 기록은 보이지 않습니다. 새 입력의 실행에서는 다시 최근 기록부터 표시합니다.
- **재생 제어와 여백**: 하단 재생 바의 실제 높이를 측정해 페이지 끝 여백과 스크롤 여백을 맞춥니다. 좁은 화면이나 글자 크기 변경으로 바가 높아져도 마지막 학습 안내에 접근할 수 있습니다.
- **학습 안내**: ‘예상해 보기’에서 다음 상태 질문을, 패널의 ‘읽는 법’에서 범례 설명을 펼칩니다. 현재 사건 설명과 상태 범례는 기본으로 보입니다. 하단의 ‘관찰에서 설명으로’와 같은 입력 비교 활동도 유지합니다.
- **키보드**: 탭의 좌우 방향키와 Home/End는 탭만 선택하며 실행 단계를 바꾸지 않습니다. Tab으로 선택한 패널의 조작 요소에 접근합니다. 조작 요소 밖의 실행 단축키와 하단 재생 제어는 기존 규칙을 따릅니다.
- **같은 Step**: 패널 숨기기·탭 전환·설정 접기는 인덱스·집계·재생 상태를 바꾸지 않습니다. 숨겨진 패널도 현재 Step을 받습니다. 코드·기록의 자동 세로 스크롤은 사용하지 않습니다. 호출 트리는 활성 호출의 가로 위치만 보정합니다. 단계 이동으로 페이지 위치를 강제로 바꾸지 않습니다.
- **비교**: 재귀/반복과 BFS/DFS는 같은 입력·한도의 독립된 실행을 사용합니다. ‘단계 보기’ 또는 ‘과정’ 버튼은 자동 실행을 멈추고 해당 방식에서 보던 위치로 복원한 뒤 설정을 접고 코드 패널에 포커스를 옮깁니다. 전체 영역 표시 선호는 유지합니다. 같은 Step 번호를 같은 계산량으로 해석하지 않습니다.
- **초기화**: 입력 변경은 실행·비교 기록을 초기화합니다. 모듈이나 트리 활동 변경도 새 실습을 시작합니다. 설정 열림·전체 영역 표시 선호만 모듈 사이에 유지되며 새로고침하면 기본값으로 돌아갑니다.

학생 입력과 화면 선택은 서버 전송이나 자동 저장 없이 브라우저 메모리에서만 유지합니다. 일반 여섯 패널 활동의 비교는 한 실행씩 관찰하며, 아래의 미로 비교 전용 화면은 두 그림을 함께 재생합니다.

## 그림 편집과 미로 비교 확장

그래프·트리의 설정 안에 그림 편집 도구를 추가했습니다. 그림에서 정점을 넣거나 지우고, 연결할 두 정점을 고르거나 간선을 지울 수 있습니다. 드래그 배치는 실행 기록을 유지하는 표시 조작이며 연결 수정은 이전 실행을 초기화합니다. 행렬·리스트를 입력 중이면 그림 수정을 잠급니다.

**그래프와 탐색 → 미로 BFS·DFS**는 사용자의 ‘코드 없이 직접 수정하며 두 탐색의 차이만 나란히 비교’ 요청에 따라 여섯 영역의 예외로 변경했습니다. 두 그림과 공통 편집 도구를 항상 보여 주고, 어느 그림을 수정해도 같은 미로에 반영합니다. ‘같이 탐색’과 ‘한 칸씩’은 새 칸을 발견하는 장면을 함께 재생하며 먼저 출구를 찾은 쪽은 그 상태를 유지합니다. ‘결과 비교’는 양쪽의 발견 시점 또는 마지막 안전한 상태로 바로 이동합니다. 발견한 칸 수·경로 길이만 표시하며 코드·상태·구조·기록·분석 탭과 고정 재생 바를 제거했습니다. 768px 이상은 나란히, 더 좁은 화면은 세로 배치하고 외부 페이지 스크롤을 유지합니다. 자세한 기준은 [미로 계약](MAZE.md)을 따릅니다.
