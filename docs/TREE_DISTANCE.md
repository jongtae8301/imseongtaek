# 트리 거리·최소 공통 조상

> 현재 제공하지 않는 활동의 이전 구현 기록입니다. 2026-09-13 사용자 요청에 따라 거리·공통 조상 메뉴와 실행 예제 등록을 제거했습니다. 관련 소스·단위 검증은 참고용으로 보관하며 학생 화면에서는 접근할 수 없습니다.

교과서 기반 검토 후 사용자의 진행 요청에 따라 첫 우선순위인 트리 거리 활동을 추가했습니다. 스택 표현식·추가 재귀 등 나머지 제안의 구현을 뜻하지 않습니다.

## 학습 활동과 출처

교과서 PDF 131–135쪽 / 인쇄 140–144쪽의 계통도·거리 계산 활동을 바탕으로 합니다. 이전 검토에서 본문과 PDF 133쪽 렌더링을 확인했으며 원본은 보존했습니다. 예제 연결은 A→B,C / B→D,E / E→F,G입니다. ‘거리’는 두 노드 사이 경로의 간선 수이며 실제 생물학적 거리 추정이 아닙니다.

- 예상: 같은 깊이의 D와 E에서 종료해도 되는지 생각합니다.
- 관찰: a·b의 부모 이동과 다음 줄의 distance 증가를 나누어 봅니다.
- 설명: 두 노드가 B에서 만나며 거리 2가 되는 과정을 설명합니다.
- 비교: 같은 트리·노드 쌍에서 깊이/배열 방법을 바꿉니다. D–E는 깊이 방식에서 D부터, 배열 방식에서 E부터 이동하지만 결과가 같습니다.
- 재적용: A–G(거리 3·LCA A), F–G(거리 2·LCA E), G–G(거리 0·LCA G), 편집한 일반 트리에 적용합니다.

## 두 실행 방식

**깊이 비교**는 준비된 parent·depth를 사용합니다. `a != b`인 동안 더 깊은 쪽을 올리고, 같은 깊이면 a부터 올립니다. 이진 여부와 관계없이 검증된 트리에 적용하는 변형 예제입니다.

**배열 인덱스**는 교과서의 1기반 배열과 큰 인덱스 쪽을 부모로 올리는 원리를 따릅니다. 부모 인덱스는 `position[v] // 2`입니다. 루트 1, 자식 2i·2i+1 규칙이며 자식 하나는 왼쪽에 놓습니다. 배열 위치를 직접 편집하는 기능은 없습니다. 자식이 셋 이상인 일반 트리에서는 오류 원인과 깊이 방식으로 바꾸는 방법을 안내합니다.

원문의 PDF 133 / 인쇄 142쪽 설명에는 ‘깊이가 같은 때 깊이가 깊은 노드’를 이동한다는 불명확한 문구가 있습니다. 구현의 종료 조건은 **같은 노드**입니다. 배열 방식도 위치 사전을 변경하는 원문 표현 대신 a/b 노드를 부모로 변경하며, 관찰용 각 이동 기록과 최종 경로를 추가했습니다. 원문 그대로의 코드는 아닙니다. PDF 135쪽의 재귀 변환 활동은 아직 제공하지 않습니다.

## Step과 화면의 대응

실행기는 `src/examples/tree-distance.ts`이며 `TraceRecorder`를 재사용합니다. 준비된 부모·깊이 또는 배열·인덱스, 이후 대입되는 a·b·distance·lca는 globals에 들어갑니다. 초기에는 네 실행 변수 모두 `unset`이며, 실제 거리 0과 구분합니다.

`tree-distance` 구조는 입력 두 노드, 현재 a/b, 각각의 누적 이동 기록, 현재 이동 간선, 누적 거리, LCA와 최종 경로를 담습니다. BFS/DFS의 발견·처리 상태와 다르므로 `search`는 null입니다. 이동 기록과 최종 경로는 실행기가 계산하며 UI에서 다시 탐색하지 않습니다.

| 사건               | 실행 후 관찰 상태                                        |
| ------------------ | -------------------------------------------------------- |
| a/b 초기 대입      | 해당 포인터와 이동 기록의 시작 노드가 생김               |
| distance 초기 대입 | 아직 없음 → 0                                            |
| while/if 비교      | 포인터 이동 없이 비교 결과를 설명                        |
| 부모 대입          | 포인터·이동 기록·현재 간선 갱신, distance는 이전 값 유지 |
| 거리 대입          | distance + 1 및 산술·대입 횟수 증가                      |
| 마지막 while 거짓  | a=b지만 lca 변수와 최종 경로는 아직 미대입               |
| lca 대입           | 공통 조상 확정 및 두 이동 기록을 연결한 최종 경로 표시   |
| 정상 종료          | 마지막 결과를 보존, 코드 줄 대응은 null                  |
| 한도 도달          | 직전 스냅샷 유지, 실행 미완료 표시                       |

그래프의 화살표는 부모→자식 관계를 유지합니다. 주황선은 방금 부모 방향으로 이동한 간선, 파란선은 확정된 두 노드 사이 경로이며 방향 탐색의 도달 경로라고 부르지 않습니다. ●a·◆b와 ◎LCA 텍스트를 색상과 함께 표시합니다. 선택 정점의 관계, 자료구조의 부모·깊이 표와 이진 배열, 코드·기록·분석은 같은 Step을 사용합니다.

## 집계와 한도

- 비교: while의 참/거짓 검사와 if의 깊이/인덱스 검사마다 1회.
- 대입: 실행 중 a/b/distance/lca 대입마다 1회. 준비된 입력은 제외.
- 산술: distance + 1마다 1회, 배열 방식은 부모 인덱스 // 2도 1회.
- 반복 몸체: 부모 이동 시 1회. 다음 거리 대입 전에는 distance보다 1 큼.
- 호출/최대 호출 깊이: 반복 구현이므로 모두 0.
- 거리 d의 정상 종료에서 비교 2d+1, 대입 2d+4, 산술 d(깊이) 또는 2d(배열), 반복 d. 지표를 합산하지 않음.

트리 높이 h에 대해 부모 이동은 최대 2h회이며, 준비된 관계 조회를 상수 시간으로 가정하면 반복은 O(h)입니다. 전처리·불변 스냅샷 복제·화면·전체 실행 기록 저장 비용은 이 설명에서 제외합니다. 현재 배열 표현은 편향 이진 트리에서 빈칸이 커질 수 있어 공간 O(h)로 소개하지 않습니다.

정점 1–8개, 자기 루프/중복 간선 없음, 부모→자식 연결 검증, 문자 입력 1,024자 제한을 공유합니다. 기본 100단계이며 더 낮은 한도의 미완료 상태는 단위 테스트에서 검증합니다. 최대 입력은 한 경로의 7개 간선을 이동하며 35개 스냅샷으로 완료합니다. 작은 입력의 동기 생성으로 충분하며 더 큰 그래프 지원은 이번 범위가 아닙니다.

입력·방법·루트·연결 변경은 타이머와 기록을 초기화합니다. 잘못된 트리는 실행 전에 거절하며 편집 미리보기에서 고칠 수 있습니다. 활동 전환은 기본 예제로 새 실습을 시작합니다. 방법 전환은 두 입력을 유지하지만 이전 관찰 위치를 저장하지 않습니다. 재귀 방식·두 방법 동시 비교·저장·서버 전송은 제공하지 않습니다.
